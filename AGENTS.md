# Checks

CI runs the checks below, in this order. Rust is 1.89.0, the channel in `rust-toolchain.toml`.

`docs/source/*.rst` is generated by `bash docs/scripts/export_org_to_rst.sh` from `docs/orgmode`. The README samples and the cog blocks are generated too. Do not edit those by hand. `docs/build.sh` exports before Sphinx, and so does `docs.yml`, so a checkout does not need the rst pages. `conf.py`, `_static/` and `_templates/` stay in git.

## Format, clippy, test

`check.yml`:

```
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test --locked
```

## Licenses

`deny.yml` installs cargo-deny 0.20.2 and runs:

```
cargo deny check
```

## cog

`version.yml` installs cogapp 3.6.0, not cocogitto (both install a command named `cog`), and runs:

```
cog --check @cogfiles.txt
```

Regenerate with `cog -r @cogfiles.txt`. The only hand-written version is `version` in `Cargo.toml`.

## Changelog

`changelog.yml` installs towncrier 26.9.0 and drafts with the version from `Cargo.toml`:

```
version=$(sed -n 's/^version = "\(.*\)"/\1/p' Cargo.toml)
towncrier build --draft --version "$version"
```

Do not edit `CHANGELOG.md`. Add one fragment per change under `changelog.d/`, named `<PR number>.<type>.md`. The type is one of `feature`, `bugfix`, `doc`, `removal` or `misc`. A change with no pull request yet can use `+<branch>.<type>.md`. Write the entry as one Markdown bullet body, one sentence per line, with no leading dash. A fragment whose name has no configured type fails the draft.

## Measurements

`measurements.yml`:

```
python3 scripts/check_measurements.py
```

## Derivations

`derive.yml` on Python 3.12. SymPy (`python -m pip install sympy`):

```
python derive/sympy/fj.py
python derive/sympy/jury.py
python derive/sympy/golden.py
git diff --exit-code derive/golden
```

Sollya. The program's quit takes no status, so the verdict is the last line:

```
sollya derive/sollya/rounding.sollya
sollya derive/logit_lipschitz.sollya
```

Those pass when the last line is `all certificates hold` and `certified`. Lean is `lake build` in `derive/lean`. The toolchain is `derive/lean/lean-toolchain`.

## Docs

`docs.yml` exports, then builds with warnings as errors, then runs impeccable 4.5.2 (exit 2 on a finding the config does not ignore):

```
bash docs/scripts/export_org_to_rst.sh
python -m pip install -r docs/requirements.txt
sphinx-build -b html -n -W docs/source docs/build
npx -y impeccable@4.5.2 detect docs/build
```

The export uses pandoc, or emacs when pandoc is absent.

## Security

This crate does not authenticate voters. A ballot is only as honest as the tracker it came from, and any process that can write the tracker can vote under any name.
